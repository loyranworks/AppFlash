# AppFlash

**你的应用，一闪即达。**

**落雁工作室** · 巧思成形，琢而至美。

[English](README.en.md) · 简体中文

专注于应用切换的 Windows / macOS 桌面工具。一个自定义 Prefix 加一个字母，启动、唤起、切换或最小化常用应用。没有搜索框，不添加与切换无关的功能。

> 当前处于调试阶段：Windows 可构建；macOS 原生适配尚待实机验收。同一个 loyranworks/AppFlash 仓库已公开；通过正式 Release 测试签名升级，仍不承诺稳定版质量。

## 快速开始

1. 打开 AppFlash。首次运行没有预置绑定，不会擅自占用应用快捷键。
2. 在左侧「应用」选择 Prefix，默认推荐单键 **Alt**。勾选多个键表示必须同时按住。
3. 在「应用」批量导入或手动添加应用，分配唯一的 A–Z 字母。
4. 点击「保存并生效」，关闭设置。例如 Chrome 分配 C 后，按 **Alt + C**。

关闭设置不会退出。Windows 托盘 / macOS 菜单栏菜单提供设置、暂停 / 恢复、关于 AppFlash 和退出。在 macOS 上，从 Finder 再次打开 AppFlash 会恢复设置窗口，包括已最小化的窗口。「关于」显示当前版本及工作室署名，跟随界面语言切换。暂停会释放已注册快捷键；设置处于前台时不执行切换，避免编辑误触。

## 批量导入

扫描的是**当前有窗口的应用**，不是硬盘上所有已安装软件。

1. 先打开想导入的 Chrome、飞书、文件管理器等应用。
2. 在「应用」点击「批量导入」，检查真实图标、名称和完整地址。
3. 按名称或地址筛选，勾选条目，在右侧填写字母。输入字母会自动勾选条目。
4. 点击「添加到列表」：这一步仅更新待保存列表，不会接管快捷键。
5. 检查后点击一次「保存并生效」，全部绑定立即更新，**不需要重启**。

相同路径不会重复添加；已存在路径不可再次选择。同名不同地址可分别添加。字母重复会阻止导入，请调整后再试。未发现的应用可以手动「添加」：Windows 填写 exe 完整路径；macOS 填写 /Applications/App.app 这样的应用包路径。不支持目标应用启动参数。

## 快捷键与应用管理

- Prefix 支持 Ctrl、Alt、Shift、Win（macOS 为 Command）及其组合，至少选一个。
- 每个应用一个唯一 A–Z 字母，输入大小写均可。留空字母可保留条目但暂不绑定。
- 同时最多绑定 26 个应用；列表最多保留 500 个条目，可滚动而不会无限拉长窗口。
- 点击应用或字母圆框编辑名称、地址与字母。添加、删除与排序在保存后生效。
- 保存检查系统注册冲突；失败尝试回滚旧绑定。若回滚失败，界面明确提示退出重开。

**快捷键冲突。** 默认使用 Alt；如果某个绑定与常用应用或系统快捷键重叠，可更换字母或前缀。测试前退出使用相同绑定的旧 AHK 脚本。

## 按一次与连续按的行为

| 应用状态 | 行为 |
| --- | --- |
| 没有运行窗口 | 启动目标应用 |
| 在后台或已最小化 | 唤起 / 恢复窗口 |
| 只有一个窗口且在前台 | 再按一次最小化，随后再按可恢复 |
| 多个窗口 | 连续按在稳定窗口顺序中循环，走完后最小化全部目标窗口 |

连续按指反复按下并松开字母，不是按住字母触发自动重复。切到其他应用或关闭目标窗口时会调整循环状态。Windows 按完整进程路径匹配；特殊启动器、UWP 宿主、管理员窗口和 macOS 权限限制仍需实机验收。

## 贴边提示

平时隐藏。按住 Prefix **500ms（默认 0.5 秒）**后出现字母与真实应用图标，松开 Prefix 隐藏。快速切换不需要等待提示。圆框、线条、慢速流光与目标高亮提供轻量反馈，贴边不显示应用名称。

可设置启用 / 关闭、延迟（0–10 秒）、左 / 右侧、字母背景色，以及 A–Z 字母顺序或手动顺序。手动顺序在「应用」使用 ↑ ↓ 调整并保存；切换排序方式不覆盖手动列表顺序。原生磨砂不可用时回退到半透明背景。大量绑定使用紧凑尺寸，多屏 / DPI 效果尚待实测。

## 通用设置

应用标识恢复为最初的圆角方底镂空闪电。运行时设置图标与系统托盘背景跟随「字母背景色」；设置即时预览，保存后托盘与窗口图标生效。暂停切换时使用灰色 #343840，恢复后回到已保存颜色。关闭贴边提示仍可调整颜色。安装包、exe 文件与 macOS Dock 图标使用静态默认色，不随设置实时改变。

- **界面语言**：简体中文 / English，立即保存并切换设置、对话框、状态文字与托盘菜单，不丢失其他未保存的修改。应用名称、文件路径、Release 原文和第三方系统错误不强行翻译。
- **开机启动**：默认关闭，开关立即生效，无需点击保存。开启后登录系统静默驻留，不弹设置。请使用固定安装路径；移动开发版 exe 后需重新设置启动项。
- **版本更新**：启动约 3 秒后及每 6 小时检查，也可手动检查。仅确认后下载、校验签名与版本并安装。未保存编辑阻止升级；安装前备份 config.pre-update.json，备份或校验失败不安装。

仓库已公开，客户端无需 GitHub Token。必须发布含 latest.json 和签名安装包的正式 Release 才能检查升级。普通代码 push 不发布版本，版本 tag 才触发构建。详见 [发布与升级](docs/releases.md)。

## 配置与隐私

实际位置见「通用 → 配置位置」。Windows 通常为 %APPDATA%/local.appflash.desktop/config.json；macOS 通常为 ~/Library/Application Support/local.appflash.desktop/config.json。

配置写入临时文件后原子替换。损坏配置禁止覆盖，请先备份再修复。旧配置缺少语言时默认中文；旧启动参数会被忽略并在下一次保存时移除。原 AHK / INI 不自动迁移、不修改。分享配置前注意其中包含本机应用名称和完整路径。

## 开发

需要 Node.js / npm、Rust 稳定版与平台构建工具。Windows 需要 MSVC C++ Build Tools 和 WebView2；macOS 需要 Xcode Command Line Tools，配置的最低系统为 macOS 12。

    npm install
    npm run dev
    npm test
    npm run check
    npm run build

Windows 安装包输出到 src-tauri/target/release/bundle/nsis/。生成带更新签名的安装包需要维护者签名私钥，见发布文档。更新签名不等于操作系统代码签名；macOS 构建使用完整应用包的 ad-hoc 临时签名，首次启动仍需手动允许。Windows 代码签名与 macOS Developer ID 签名 / 公证尚未完成，分发可能出现安全警告。

ui/ 为无框架设置与提示界面；src-tauri/src/ 为配置、绑定事务、窗口循环和更新；其中 platform/ 为 Win32 / macOS Swift 原生适配；design/ 保留设计历史。
