# Studio signature fonts

Derived from the user's Loyran Works VI bundle, 06-Fonts/Playfair.ttf (Playfair Display) and NotoSerifSC.ttf (Noto Serif SC). These fonts apply only to the studio name, not the settings UI or AppFlash identity.

The local WOFF2 files contain only the glyphs used by "loyran works." and "落雁工作室", respectively. Variable weight is instantiated at Regular (400); subsetting and WOFF2 conversion use FontTools. The original font names and accompanying SIL Open Font Licenses are retained. No network font requests are made.

If either studio name changes, regenerate the corresponding subset from the original VI font, keeping its OFL license.
