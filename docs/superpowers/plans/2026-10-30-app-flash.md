# AppFlash Implementation Plan

**Goal:** Implement the approved application-only switcher in the selected workspace. Freeze the A/circle/crack icon for this implementation.

**Architecture:** Tauri 2 hosts two local webviews: settings and an unfocusable, click-through edge hint. Rust owns configuration, transactional shortcut changes and the switching state machine. Windows uses Win32 executable-path matching. macOS uses a compiled Swift accessibility helper, with native modifier-state polling in Rust.

**Tech stack:** Rust, Tauri 2, plain HTML/CSS/JavaScript, Win32, Swift/AppKit/Accessibility. No frontend framework or bundler is required.

## Scope and acceptance
- Preserve launch when no valid windows, restore/activate from background, minimize one foreground window, cycle multiple windows then minimize all, and re-enter on the next press.
- Match exact executable or application-bundle paths; retain argument arrays. Never shell-interpolate user paths.
- Prefix is a nonempty combination of Control, Alt, Shift and Super. Application letters are unique A–Z. Register new shortcuts before removing old ones. On conflict or disk failure retain the previous saved bindings.
- Settings contain a bounded scrolling list, editable paths/arguments/letters, running-app batch selection, one save action, prefix controls, overlay toggle/delay/side/color, and the approved slogan.
- Overlay normally remains hidden. Native modifier polling reveals after the configured delay and hides on release. Registered hotkeys dispatch switching immediately, without waiting for hint appearance. Suppress held-letter repeats.
- Native tray/menu has settings, pause/resume, exit. Closing settings hides rather than exits. Single-instance lock avoids two switchers fighting for shortcuts.
- Config is stored in platform app data, atomically replaced, schema-validated. Do not migrate or modify original AHK config implicitly.
