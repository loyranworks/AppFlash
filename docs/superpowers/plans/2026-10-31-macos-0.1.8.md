# AppFlash macOS 0.1.8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one verified release containing stable self signing, reliable Mac window cycling and full-screen switching, native clear glass, Navy defaults and whole-overlay percentage scaling.

**Architecture:** Keep Windows switching unchanged. Isolate Mac cycle logic and native material setup; use the existing Swift IPC for exact window operations. Sign the main application and helper with one persistent certificate and pin the certificate identity in release verification.

**Tech Stack:** Rust, Swift/AppKit/Accessibility, Tauri 2, plain JavaScript/CSS, OpenSSL and macOS security/codesign, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-31-macos-signing-and-window-control-design.md` (approved by user 2026-10-31, Navy/B/line/flow confirmed).

## Global Constraints

- `local.appflash.desktop`, macOS >=12, original updater key and config path retained.
- Default Navy `#244b70`; glass Clear on macOS >=26, vibrancy fallback; retain spine/connectors/flow and reduced-motion support.
- `hint.scale` integer 50–150, default 100 for old configs; scale all geometry and content uniformly.
- Full-screen activation preserves Spaces/full-screen. End of full-screen round hides the app; next round unhides it.
- Only parent operates GUI/keychain/GitHub. CGEvent temporary combinations are explicitly authorized. Private key only restricted local backup and this repository Actions Secrets; no VI edits.

## Review Focus

- A→B replacement changes executable hash but preserves certificate-bound requirement and actual AX access.
- Starting on last-enumerated window and delayed focus must still visit every window before collapse; failed action must not advance.
- Full-screen target and normal target both receive real focus, with no unconditional unsupported minimized writes.
- Old configs lacking scale load as 100; endpoints, non-integers and out-of-range values are validated; scale does not clip low-resolution layouts.
- Transparent WebView must reveal native glass; cross-full-screen overlay stays nonactivating and click-through; Windows retains its original material path.

**Interfaces:** Mac cycle consumes shared `Window` and `Action`, produces `Cycle::next` and success-only state advancement (clone/commit is acceptable). Swift accepts a batch collapse command for IDs and preserves full screen using app hide/unhide.
