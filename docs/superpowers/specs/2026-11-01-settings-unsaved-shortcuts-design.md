# 设置页未保存修改与快捷切换

用户已明确指定：设置打开且无未保存修改时可以切换；有未保存修改时暂停，并提供特别明显的提示。本次直接执行这一小范围规则，不增加设置开关。

以真实草稿差异驱动后端拦截，替代窗口焦点拦截。始终允许切换会干扰编辑，继续按焦点拦截不能满足首次使用体验。保存成功或手动恢复原值即可解除；保存失败仍暂停。手动暂停独立保留。

编辑弹窗与批量导入中尚未加入主列表的内容也计入未保存修改，取消弹窗后重新计算。关闭或切走设置保留已有草稿及暂停状态，避免关闭窗口绕过未保存条件；重新打开可以继续保存。即时保存的语言、登录启动和浏览设置本身不产生待保存状态。

设置底部使用持续、醒目的暖色状态，解释暂停原因并指向保存；尝试应用快捷键时在现有玻璃贴边中显示同一提示，提示仍遵守六秒寿命，保存后只清除这一提示，保留无关错误。不改变窗口控制、主题、签名和更新行为。

异步状态通知有序发送。保存时若用户继续编辑，不覆盖新输入或错误恢复快捷键；失败保留草稿。回归覆盖干净页面、编辑/恢复、取消、保存成功/失败、即时设置及后端按键提示。
