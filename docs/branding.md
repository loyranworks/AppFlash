| English | loyran works. | Make Ideas Work Beautifully |

Keep language variants separate. Preserve the trailing period in the English studio signature. Formal English brand name: Loyran Works.

AppFlash places the signature below APP / FLASH in the sidebar. The application icon, user-selected accent and application slogan remain independent. Per the user’s refinement, studio text inherits the existing UI font (Segoe UI / Microsoft YaHei / sans-serif) rather than VI brand fonts. Both language names inherit the APP / FLASH footer size (10 px) and muted color (#9ba9b1); the motto is one pixel smaller (9 px) in the same color. The studio block follows APP / FLASH with an 8 px gap, its motto with a 3 px gap; an 18 px bottom inset places the compact footer lower. The unused brand fonts and their licenses have been removed from the UI bundle.

The existing native About menu displays AppFlash, the actual package version and the selected-language studio text. Windows uses About comments; macOS uses credits. Menu refresh follows the existing immediate language-save flow. Native About typography follows the OS, not the sidebar web fonts.

Do not replace the AppFlash icon with the studio bird, change copyright ownership, alter product names, or add bilingual stacking as part of a studio-signature change.

The sidebar includes an 44 × 52 px decorative studio mark beside all three footer lines: APP / FLASH, studio name and motto, using the approved V6 graphical master from the final horizontal navy lockup, without its wordmark. A CSS mask preserves the original shape and inherits the footer color.
